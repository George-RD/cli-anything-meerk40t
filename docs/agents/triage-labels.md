# Triage labels

The Matt Pocock workflow uses these canonical state roles. The repo currently has no competing state vocabulary, so use the defaults when the labels are present or created through normal repository administration.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgement |
| `wontfix` | `wontfix` | Will not be actioned |

Use GitHub's ordinary `bug` and `enhancement` labels for category when applicable.
