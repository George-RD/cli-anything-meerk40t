The mechanism

A job crosses a boundary before the laser does.

Agents can do the repetitive preparation. The manifest, material profile, and preflight make that work inspectable. Calibration and physical operation stay with a person at the machine.

  1. A

    Describe

    Open an SVG or build geometry with element commands.

    elements rect · text · polyline
  2. B

    Resolve

    Select the machine and material profile instead of hand-typing settings.

    --machine sculpfun-s9
  3. C

    Prepare

    Write a job SVG, G-code, and a manifest that records what produced them.

    job prepare
  4. D

    Preflight

    Re-check file hashes and the settings fingerprint before the job moves on.

    job preflight
  5. Operator boundary
  6. E

    Frame & run

    Connect, check origin and placement, then operate the machine in person.

    device check · frame

ESTIMATED

Useful for inspection and preflight. Calibrate on scrap before a real frame or burn.

Safety boundary

Estimated is not calibrated.

○
NO HARDWARE

Safe offline work

  • Build or edit geometry
  • Resolve a machine and material profile
  • Export job SVG and G-code for inspection
  • Verify hashes and settings fingerprint

--allow-estimated acknowledges an inspection-only result. It does not make it burn-ready.

!
LASER CONNECTED

Operator present

  1. Run a calibration ladder on scrap
  2. Record the result with materials record
  3. Prepare again without --allow-estimated
  4. Check focus, origin, glasses, ventilation, and placement

Frame and run only from calibrated settings, at the machine.

The MeerK40t console server is unauthenticated.

Keep it bound to loopback and firewall-restricted. Request correlation is not authentication, and the port must never be exposed to the internet.
